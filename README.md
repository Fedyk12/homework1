## Как сдавать

- Каждая задача — отдельный файл: `task1.py`, `task2.py`, `task3.py`, `task4.py`, `task5.py`.
- Каждый файл должен запускаться без ошибок.
- Проверка личная: примеры из условия должны давать результат, как в примере вывода.

## Задача 1. Пары чисел с заданной суммой

Дан список чисел и целевая сумма:

```python
nums = [1, 2, 3, 4, 5, 6, 4]
target = 7
```

Выведите все пары чисел, которые в сумме дают `target`.

Пример вывода:

```
(1, 6)
(2, 5)
(3, 4)
```

Требования:

- Пара выводится один раз: `(1, 6)` и `(6, 1)` — это одна и та же пара.
- Пара из двух одинаковых чисел допустима, только если это число встречается в списке минимум дважды.
- Порядок пар в выводе не важен.

## Задача 2. Второй по величине элемент

Дан список чисел. Выведите второй по величине различный элемент, то есть наибольшее число, строго меньшее максимума. Если такого нет — выведите `Второго по величине элемента нет`.

Примеры:

```python
nums = [4, 1, 7, 7, 3]   # вывод: 4
nums = [10, 3]           # вывод: 3
nums = [5, 5, 5]         # вывод: Второго по величине элемента нет
```

## Задача 3. Частота слов

Дан список слов:

```python
words = ["кот", "пёс", "кот", "кот", "ёж", "пёс", "кот"]
```

Выведите топ-3 самых частых слов с нумерацией:

```
1. кот — 4
2. пёс — 2
3. ёж — 1
```

## Задача 4. Учёт посещаемости

Даны два списка (внутри есть дубликаты):

```python
lecture = ["Аня", "Борис", "Вика", "Гоша", "Аня"]
seminar = ["Вика", "Дима", "Борис", "Ева"]
```

Выведите отчёт:

```
Всего уникальных студентов: 6
На обеих парах: ['Борис', 'Вика']
Только на лекции: ['Аня', 'Гоша']
Хотя бы на одной: ['Аня', 'Борис', 'Вика', 'Дима', 'Ева', 'Гоша']
```
